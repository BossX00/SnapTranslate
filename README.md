# SnapTranslate

> Instant Thai ↔ English translator for Windows via **`Ctrl + Right-Click`** — featuring a floating Popup mode and a background Cut-Translate-Paste Typing mode.

โปรแกรมแปลภาษาบน Windows ที่ใช้ Google Translate โดยกด **`Ctrl + คลิกขวา`** บนข้อความที่คลุมดำไว้ สลับภาษาอัตโนมัติระหว่าง **ไทย ↔ อังกฤษ**

---

## ความสามารถหลัก (Features)

### 1. โหมดป๊อปอัป (Popup Mode — ไอคอนสีน้ำเงิน)
- คลุมดำข้อความในหน้าเว็บ เอกสาร หรือโปรแกรมใดๆ แล้วกด **`Ctrl + คลิกขวา`**
- เปิดหน้าต่างแสดงผลแปลภาษาเป็นภาษาตรงข้ามทันที (**ไทย → อังกฤษ** หรือ **อังกฤษ → ไทย**)
- มีปุ่ม **สลับภาษา (`⇄`)**, **แทนที่** (วางคำแปลแทนที่ข้อความที่เลือก), และ **คัดลอก**
- กู้คืนค่าคลิปบอร์ดเดิมให้หลังอ่านข้อความที่คลุมดำ

### 2. โหมดพิมพ์ (Typing Mode — ไอคอนสีเขียว)
- คลุมดำข้อความที่กำลังพิมพ์อยู่ (เช่น ในช่องแชท, Notepad, เบราว์เซอร์, Word) แล้วกด **`Ctrl + คลิกขวา`**
- ไม่เปิดเมนูแปล แต่จะดึงข้อความด้วย `Ctrl + X` แปลเบื้องหลัง และนำคำแปลมาวางกลับให้ทันที (`Ctrl + V`)
- รักษาช่องว่างและการขึ้นบรรทัดใหม่หัว-ท้าย และคืนข้อความต้นฉบับกลับเข้าช่องพิมพ์ให้อัตโนมัติหากการแปลล้มเหลว

### 3. เปลี่ยนโหมดที่ไอคอนมุมขวาล่าง (System Tray)
- **คลิกซ้าย** ที่ไอคอน SnapTranslate มุมขวาล่าง เพื่อสลับระหว่าง **โหมดป๊อปอัป** ↔ **โหมดพิมพ์** ทันที
- **คลิกขวา** เพื่อเลือกโหมด, **หยุดใช้งานชั่วคราว**, ตั้ง **เปิดโปรแกรมอัตโนมัติเมื่อเปิดเครื่อง**, ดู **วิธีใช้งาน**, หรือ **ออกจากโปรแกรม**

## ความต้องการระบบ (Requirements)

- Windows 10 / Windows 11 (x64)
- [.NET 8.0 Desktop Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/8.0) (หรือ .NET 8.0 SDK สำหรับ build จากซอร์สโค้ด)

---

## การ Build และใช้งาน (Build & Run)

```powershell
dotnet publish SnapTranslate.csproj -c Release -r win-x64 --no-self-contained -p:PublishSingleFile=true -o dist
```

หลังจาก build แล้ว สามารถรันได้ทันทีผ่าน [run.bat](run.bat) หรือเปิด `dist\SnapTranslate.exe`
